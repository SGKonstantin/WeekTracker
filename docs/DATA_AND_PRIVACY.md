# Данные и приватность

WeekTracker не требует внешней базы данных или отдельного сервера. При пользовательской установке приложение работает в собственной копии Google Таблицы пользователя. Standalone-режим для разработки может создать отдельную таблицу `WeekTracker Data`.

В таблице находятся:

- настройки приложения;
- задачи;
- определения привычек;
- история отметок привычек.

Spreadsheet ID и зарегистрированный Web App URL хранятся в Apps Script Script Properties, а не в исходном коде. Исходный шаблон не получает данные пользовательской копии. Пользователь контролирует Google-аккаунт, таблицу, Apps Script-проект, deployment и выбранный уровень доступа Web App.

## Удаление данных

Задачи и привычки удаляются через soft delete. Неактивные записи могут физически оставаться в таблице, а история HabitLog сохраняется после удаления привычки. Автоматической постоянной очистки сейчас нет.

## Ответственность владельца

Владелец установки должен самостоятельно проверить разрешения Google-аккаунта и настройки доступа Web App. Описание модели хранения не является обещанием дополнительных гарантий безопасности сверх поведения приложения и используемых сервисов Google.

Не публикуйте Spreadsheet IDs, Apps Script IDs, deployment URLs, credentials, логи или скриншоты с персональными данными без очистки.
