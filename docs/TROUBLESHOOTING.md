# Решение проблем

## WeekTracker сообщает, что не настроен

Вернитесь в свою Google Таблицу, выберите **WeekTracker → Первоначальная настройка**, завершите авторизацию и снова откройте Web App.

## Требуется авторизация Google

Собственной копии скрипта нужен доступ для работы с вашей Google Таблицей. Просмотрите запрошенные разрешения и используйте аккаунт владельца установки.

## Таблица не найдена

Таблица могла быть удалена или стать недоступной текущему аккаунту. Откройте нужную копию таблицы под аккаунтом владельца и выберите **WeekTracker → Первоначальная настройка**.

## Меню «Открыть приложение» не показывает ссылку

После развёртывания один раз откройте Web App URL непосредственно из окна deployment. При этом WeekTracker зарегистрирует ссылку для меню таблицы.

Если ссылка не зарегистрировалась или deployment был заменён, выберите **WeekTracker → Указать ссылку Web App** и вставьте действующий URL с окончанием `/exec`.

## Для разработчиков: Apps Script API выключен для clasp

Включите Google Apps Script API в настройках Google-аккаунта, немного подождите и повторите команду.

## Для разработчиков: не работает `clasp login`

Проверьте выбранный Google-аккаунт и завершение авторизации в браузере. При устаревшей сессии выполните `clasp logout`, затем снова `clasp login`.

## Для разработчиков: отсутствует `.clasp.json`

Создайте Apps Script-проект или привяжите существующий через clasp. Файл намеренно исключён из Git и должен создаваться локально каждым разработчиком.

## Для разработчиков: изменения Web App не видны

Для разработки используйте URL с `/dev`. Для релизного `/exec` обновите versioned deployment после `clasp push`.

## Ошибка `npm run check`

Исправьте первый упавший этап: syntax, Vitest или project safety. Не обходите security/privacy failures.

## Название привычки отклонено

Названия активных привычек сравниваются без учёта регистра и пробелов по краям. Удалите существующую активную привычку или выберите другое название.

## Новый планировщик пуст

Это ожидаемо: новая установка начинается с 0 задач и 0 привычек.
