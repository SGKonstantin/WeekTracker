# WeekTracker

[English version](README.en.md)

WeekTracker — бесплатный open-source недельный планировщик и трекер привычек, работающий как Google Apps Script Web App с хранением данных в собственной Google Таблице пользователя.

Отдельный сервер не требуется: пользователь разворачивает собственную копию в своём Google-аккаунте.

## Основные возможности

- Недельный планировщик с понедельника по воскресенье
- Создание и редактирование текста задач
- Отметка выполнения через checkbox
- Мягкое удаление задач
- Изменение порядка задач внутри одного дня
- Переход к предыдущей и следующей неделе
- Кнопка «Сегодня» для возврата к текущей неделе
- Дневной и недельный прогресс задач
- Привычки с выбором дней недели
- Отметки выполнения и прогресс привычек
- Защита от двух активных привычек с одинаковым названием
- Адаптивный интерфейс и optimistic UI
- Мягкое удаление задач и привычек для сохранения истории

Задачи можно менять местами только внутри одного дня. Перенос между днями пока не поддерживается.

## Установка

Основной способ установки для пользователя — собственная копия Google Sheets Template:

[Создать свою копию WeekTracker](https://docs.google.com/spreadsheets/d/%317T7ZwIzmjOS9dhjkvPIkf44EyPINVzOCXXwXz6E1wIs/copy)

Ссылка сразу откроет создание вашей личной копии шаблона.

1. Создайте копию WeekTracker Template.
2. Выполните **WeekTracker → Первоначальная настройка**.
3. Разверните Apps Script как Web App.
4. Один раз откройте полученную ссылку.
5. В дальнейшем используйте **WeekTracker → Открыть приложение** в своей таблице.

[Подробная инструкция по установке](docs/INSTALLATION.md)

## Данные и приватность

Данные находятся в Google Таблице самого пользователя, а Spreadsheet ID хранится в Script Properties. Внешний сервер не требуется. Удаление задач и привычек сейчас выполняется через soft delete; автоматической постоянной очистки нет.

Подробнее: [данные и приватность](docs/DATA_AND_PRIVACY.md).
