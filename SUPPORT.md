# Поддержка и обратная связь

## Сообщить об ошибке

После публикации репозитория создайте Bug Report в GitHub Issues. Укажите шаги воспроизведения, ожидаемое и фактическое поведение, браузер и устройство.

## Предложить функцию

Создайте Feature Request в GitHub Issues. Опишите, какую проблему решает идея, ожидаемое поведение и рассмотренные альтернативы.

## Вопрос по использованию

Для воспроизводимой проблемы используйте GitHub Issues и приложите только необходимый контекст. GitHub Discussions может быть включён позже для общих вопросов.

## Как безопасно прикладывать logs и screenshots

Перед публикацией удалите Spreadsheet IDs, Apps Script IDs, deployment URLs, tokens, authorization data, имена аккаунтов и другие персональные сведения. Не прикладывайте credential-файлы.

## Материальная поддержка

Финансовые ссылки пока не опубликованы. Официальные способы поддержки могут быть добавлены maintainer'ом позже. Помочь также можно через bug reports, feature ideas, документацию и pull requests.
